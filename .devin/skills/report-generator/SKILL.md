# Report Generator

Generate a progress report for the final project based on the specified structure.

## When to use

Use this skill when you need to create a progress report for the final project, covering:
- SDD Contract (Swagger) status
- Backend and integrations progress
- Resilience implementation
- Advanced patterns
- Frontend development
- Current impediments

## How it works

The skill will guide you through creating a structured report with the following sections:

1. **Contrato SDD (Swagger)**: Status of API specification and how it guides code development
2. **Backend e Integrações**: Progress on route construction and external service integration
3. **Resiliência**: Error handling, timeouts, and retry routine implementation
4. **Padrões Avançados**: Additional strategies implemented and their development phase
5. **Frontend**: Framework choice, interface development as blind client, and secure login system
6. **Impedimentos**: Major technical difficulties faced by the team

## Output format

The report should be structured in short, direct topics following the template:

```markdown
# Relatório de Andamento: Projeto Final

## Contrato SDD (Swagger)
[Describe current status]

## Backend e Integrações
[Describe current status]

## Resiliência
[Describe current status]

## Padrões Avançados
[Describe current status]

## Frontend
[Describe current status]

## Impedimentos
[Describe current status]
```

## Usage

Invoke this skill when you need to:
- Generate a new progress report
- Update an existing report
- Structure project status information according to the required format
